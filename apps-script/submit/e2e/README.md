# 화면까지 끝에서 끝으로 돌려 보기

`../test/` 의 시험은 백엔드만 봅니다. 여기 있는 것은 **진짜 브라우저**가 사이트의 제출 · 현황판 화면을 열고,
같은 백엔드 코드(`Submit.gs` · `SubmitAdmin.gs`)와 실제로 요청을 주고받게 합니다.

- Apps Script 웹 앱 자리에는 작은 로컬 서버가 서고, 그 안에서 `Submit.gs` 가 그대로 실행됩니다 (시트 · Drive 는 `../test/harness.mjs` 의 가짜).
- Drive 의 이어 올리기 주소도 그 서버가 받습니다. CORS 는 진짜 Drive 처럼 — 올리기 주소를 만들 때 받은 출처에만 열어 줍니다.
- 구글 로그인 스크립트는 누르면 정해 둔 계정으로 로그인되는 가짜로 바꿉니다. 그 밖의 화면 코드는 저장소의 파일 그대로입니다.
- 실제 구글 서버에는 아무것도 보내지 않습니다.

## 돌리기

```bash
# 한 번만: 브라우저 조종 도구와 크로미움 (저장소 밖이나 .debug/ 처럼 git 이 무시하는 곳에)
mkdir -p .debug/pw && (cd .debug/pw && npm init -y >/dev/null && npm i playwright-core && npx playwright-core install chromium)

PW_DIR=.debug/pw node apps-script/submit/e2e/run.mjs              # 전부 (2–3분)
PW_DIR=.debug/pw node apps-script/submit/e2e/run.mjs 현황판        # 이름에 '현황판' 이 든 시나리오만
PW_DIR=.debug/pw SHOTS=.debug/shots node apps-script/submit/e2e/run.mjs   # 장면마다 화면도 찍어 둔다
```

| 환경 변수 | 뜻 |
|---|---|
| `PW_DIR` | `playwright-core` 를 설치한 폴더. 저장소에 `node_modules` 를 두지 않으려고 따로 받습니다 |
| `CHROMIUM` | 크로미움 실행 파일 경로. `playwright-core install` 이 멈추거나(새 Node 에서 가끔 그렇습니다) 이미 받아 둔 것이 있을 때 |
| `SHOTS` | 화면을 찍어 둘 폴더 |
| `E2E_PORT` | 로컬 서버 포트 (기본 5503, 사이트는 그다음 번호) |

## 무엇을 보나

| 시나리오 | 확인하는 것 |
|---|---|
| 참가자 | 로그인 → 팀 찾기 → 저장 → 20MB 를 조각 셋으로 Drive 에 직접 → 다시 올리기(옛날 자료) → 받아서 확인 → 직접 올리기가 막힌 환경의 우회 경로 → 내리기. 다른 팀 자료 · Drive 주소가 응답 어디에도 없는지 |
| 명단에 없는 계정 | 안내와 자기 주소 · 명단에 넣으면 바로 들어오는지 · 서버가 HTML 오류를 한 번 돌려줘도 한 번만 저장되는지 |
| 로그인 유지 | 구글 토큰이 끝난 뒤에도 세션으로 이어지는지 · 올리는 도중 세션이 사라져도 다시 로그인하면 같은 표로 마무리되는지 · 계정을 바꾸면 앞사람 글자가 지워지는지 |
| 직접 올리기 | 조각이 사라지거나 응답이 끊겨도 이어 올려 같은 파일이 되는지 |
| 마감 | 마감 전에 시작한 것만 유예 안에 받는지 · 마감 뒤 화면이 잠기고 서버가 거절하는지 · 운영진 대리 제출 |
| 현황판 | 열람 링크 · 틀린 코드 · 카드 20장 · PDF 를 화면 안에서 열기(올린 파일과 같은지) · 받기 · 새 제출이 그 카드에만 반영 · 링크를 끄면 닫히는지 · 운영진 링크 |
| 휴대폰 화면 | 가로로 넘치지 않는지 |
| 인기투표 | 명단에 없는 계정 거절 · 열기 전 안내 · 운영진이 열면 참가자 화면이 저절로 바뀌는지 · 우리 팀 막힘 · 3팀 제한 · 확인 코드가 시트의 검증값과 같은지 · 다시 내면 마지막 것만 · 시트에 이메일 · 이름이 없는지 · 마감 뒤 서버 거절 · 참가자가 여는 요청을 보내도 거절 |

진짜 구글 · 진짜 Drive 와의 연결(특히 브라우저가 Drive 로 직접 올릴 수 있는지)은 여기서 확인할 수 없습니다.
그것은 배포한 뒤 시트 메뉴의 `설정 점검` 과 연습 팀(00)으로 확인합니다 — [SUBMIT.md](../../../SUBMIT.md) 1절.
